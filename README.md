- Use the **Family Notes** panel (bottom of every page) to add notes and votes
- Notes are saved in your browser's local storage
- Download notes as a `.txt` file using the ⬇ Download button

## Deploy to GitHub Pages
1. Upload the contents of this repo
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)`
4. Your site will be live at `https://[username].github.io/[repo-name]`
